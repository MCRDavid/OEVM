Data sources and transparency

OEVM is a personal, experimental project for learning about AI tools. Much of its code and text was written with an AI assistant, and it will contain mistakes. Charger data comes from the operators and other sources credited on every record, and remains their work. Everything is provided "as is", with no warranty or guarantee of any kind. Always check prices and availability at the charger.

Last reviewed: 2026-10-07. This page lists every source this project uses or plans to use, how each one publishes its data, the rate limits that apply, and what has been found while reading the data. It reports what was observed and when. It does not say whether anyone has met their legal duties.

Rate limits

The Public Charge Point Regulations 2023 set no limit on how often data users may request the data. Regulation 10(5) requires the data to be available free of charge without terms on its use. DfT's guidance allows terms covering the means of access, which is where operators' rate limits come from.

  • “terms and conditions covering the means of access to the data and API(s) are permissible” (DfT, Public Charge Point Regulations 2023 guidance)

This project never sends more than one request per second to any operator, and keeps within every limit an operator publishes. Automated tests check both rules.

What has been found

Differences from the OCPI 2.2.1 standard, quirks in the data and access issues, each with the date it was seen and what this project does about it. Values that are not valid are shown as unknown, never guessed. Only prices in pounds sterling are shown.

DateTypeWhat was foundHow this project handles itStatusEvidence
2026-10-07Differs from OCPI 2.2.1EVSE statuses are published as WORKING and FAULTED, which are not values in the OCPI 2.2.1 Status list.Shown as status unknown rather than guessed. Regulation 10(6)(a) uses "working" to mean an OCPI status of available, charging or reserved.Openevidence
2026-10-07Data quirkTariffs are published in three currencies (EUR, USD and GBP). Locations refer only to the GBP tariff.Only GBP prices are shown, in pence per kWh, which is how regulation 10(6)(d)(iv) describes the price in reference data. Other currencies show as price unknown and are never converted.Openevidence
2026-10-07Data quirkTariff price components give no VAT figure.Prices are shown as published, excluding VAT, and marked "VAT not stated".Openevidence
2026-10-07AccessThe feed sends no Access-Control-Allow-Origin header, so web browsers cannot read it directly.The map will use data fetched by the pipeline, not requests from visitors' browsers.Openevidence
