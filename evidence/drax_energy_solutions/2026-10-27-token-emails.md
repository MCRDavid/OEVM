# Drax Energy Solutions: token emails from Eco-Movement, 27 October 2026

Channel: three emails to the project's address, received on 2026-10-27. The sender was
Eco-Movement; no personal names were given. Each email lists the same eight networks, in a
different order, each with its own expiring link: Drax Group, GFX-GB Drax, drax-Ista, Aldi
Stores Limited, Travis Perkins, Volvo, WCCC Edgbaston and Southampton Apartment Hotels. The
emails do not say which request they answer. The project's request through Drax's PCPR form
on 2026-10-23 is shared with Eco-Movement, three of the eight labels name Drax, and on
2026-10-29 all eight networks' data was published under one OCPI party, GB GFX, so the emails
most likely answer that request; this is inferred, not stated.

The expiring links have been removed. No token is kept here; each network's token is stored
only as a GitHub Actions secret named in that network's operator file (`operators/drax_group.yaml`
and the others listed in `operators/drax_energy_solutions.yaml`).
